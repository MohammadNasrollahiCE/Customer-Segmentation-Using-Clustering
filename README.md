# Wholesale Customer Segmentation

An end-to-end **unsupervised machine learning project** for discovering customer segments from wholesale purchasing behavior using clustering algorithms, dimensionality reduction, and quantitative cluster evaluation.

The project investigates how **data preprocessing, feature representation, and clustering algorithms** affect the quality and interpretability of customer segmentation.

---

## 📌 Overview

Customer segmentation is a common application of unsupervised learning where observations are grouped according to similarities in their characteristics without predefined target labels.

In this project, the purchasing behavior of wholesale customers is analyzed using six annual spending features:

* Fresh
* Milk
* Grocery
* Frozen
* Detergents_Paper
* Delicassen

Several clustering approaches are investigated, including:

* K-Means
* Agglomerative Hierarchical Clustering
* DBSCAN
* HDBSCAN
* Gaussian Mixture Models (GMM)

Principal Component Analysis (PCA) is also investigated as an alternative feature representation before clustering.

The project does not simply compare clustering algorithms by a single metric. Instead, it follows a complete workflow:

```text
Raw Data
   │
   ▼
Exploratory Data Analysis
   │
   ▼
Preprocessing
   │
   ├───────────────┐
   ▼               ▼
Clustering        PCA
   │               │
   │               ▼
   │          Clustering
   │               │
   └───────┬───────┘
           ▼
     Cluster Evaluation
           │
           ▼
     Cluster Profiling
           │
           ▼
       Interpretation
```

# 🎯 Objectives

The main objectives of this project are:

* Explore the structure and distribution of wholesale purchasing data.
* Identify important preprocessing requirements for clustering.
* Investigate customer segmentation without dimensionality reduction.
* Compare different clustering paradigms.
* Analyze the effect of PCA on the clustering structure.
* Determine suitable cluster counts where applicable.
* Evaluate clustering quality using quantitative metrics.
* Analyze cluster distributions and customer profiles.

# 📓 Notebook Workflow

The notebooks are organized sequentially to document the complete analytical process.

---

## 01 — Exploratory Data Analysis

**File:** `notebooks/01_EDA.ipynb`

The first notebook focuses on understanding the raw dataset before applying machine learning algorithms.

Topics include:

* Dataset structure
* Data types
* Missing values
* Duplicate observations
* Descriptive statistics
* Feature distributions
* Outlier inspection
* Skewness
* Correlation analysis
* Initial visualization of purchasing behavior

The purpose of this stage is to understand the statistical characteristics of the data before selecting preprocessing techniques.

---

## 02 — Preprocessing

**File:** `notebooks/02_Preprocessing.ipynb`

This notebook prepares the dataset for clustering.

The main preprocessing considerations include:

### Log Transformation

The spending variables exhibit strong right-skewed distributions.

A logarithmic transformation is therefore investigated to reduce the influence of extreme values and produce a more suitable feature representation.

### Feature Scaling

The transformed features are standardized before distance-based clustering.

This prevents features with larger numerical scales from dominating distance calculations.

The resulting processed dataset is saved as:

```text
data/cleaned_log_data.csv
```

---

# 🔵 03 — K-Means Clustering

**File:** `notebooks/03_kmeans.ipynb`

K-Means is used as the primary centroid-based clustering algorithm.

Different values of `K` are investigated rather than assuming the number of customer segments beforehand.

The analysis uses:

* Inertia
* Elbow Method
* Silhouette Score
* Cluster size
* Cluster profiling

The goal is to determine whether the customers form a meaningful structure in the preprocessed original feature space.

---

# 🌳 04 — Hierarchical Clustering

**File:** `notebooks/04_Hierarchical.ipynb`

Agglomerative Hierarchical Clustering is investigated as an alternative clustering paradigm.

The analysis explores the hierarchical structure of the observations and uses dendrograms to examine how customers merge into larger groups.

This provides a different perspective from centroid-based K-Means.

The resulting segmentation is evaluated using the same general principles:

* Cluster separation
* Cluster cohesion
* Silhouette Score
* Cluster sizes
* Interpretability

---

# 🌐 05 — DBSCAN & HDBSCAN

**File:** `notebooks/05_DBSCAN_and_HDBSCAN.ipynb`

Density-based clustering methods are investigated in this notebook.

### DBSCAN

DBSCAN identifies dense regions in the feature space and can classify observations as noise.

The main parameters investigated include:

* `eps`
* `min_samples`

The effect of these parameters on the number of clusters and noise observations is analyzed.

### HDBSCAN

HDBSCAN is also investigated as a hierarchical density-based alternative that can handle varying density structures more flexibly than standard DBSCAN.

This experiment is particularly useful for determining whether the dataset contains meaningful density-based structure rather than approximately spherical centroid-based clusters.

---

# 🟣 06 — Gaussian Mixture Model

**File:** `notebooks/06_GMM.ipynb`

Gaussian Mixture Models are investigated as a probabilistic clustering approach.

Unlike K-Means, which assigns each observation to one cluster based on distance to centroids, GMM models the data as a mixture of probability distributions.

This allows the model to provide:

* Cluster assignments
* Membership probabilities
* A probabilistic interpretation of cluster boundaries

Different configurations are investigated to determine whether a Gaussian mixture provides a useful representation of the customer structure.

---

# 📉 07 — K-Means with PCA

**File:** `notebooks/07_kmeans_PCA.ipynb`

This notebook investigates whether dimensionality reduction changes the clustering structure.

PCA is applied to the preprocessed spending features, and different combinations of principal components are evaluated using K-Means.

The analysis examines:

* Explained variance
* Principal component structure
* Different PCA representations
* Different values of `K`
* Silhouette Score
* Cluster distributions
* Cluster profiles

### Key Result

The clearest clustering structure observed in the project was obtained using:

```text
Algorithm        : K-Means
Representation   : PC0
Number of Clusters: 2
Silhouette Score : 0.6045
```

This result suggests that the first principal component contains a representation in which the customers can be separated into two relatively well-defined groups.

Importantly, PCA is not a clustering algorithm and does not explicitly optimize cluster separation. Therefore, the result is interpreted as evidence of structure in the data rather than as proof that two clusters are universally correct.

---

# 🧬 08 — Gaussian Mixture Model with PCA

**File:** `notebooks/08_GMM_PCA.ipynb`

The final notebook investigates GMM after PCA transformation.

The objective is to determine whether a probabilistic clustering approach identifies a structure similar to the one observed with K-Means.

The analysis includes:

* PCA representation
* GMM component selection
* Cluster assignments
* Membership probabilities
* Cluster distributions
* Silhouette analysis
* Cluster profiling

For the selected two-component PCA representation, the cluster-level silhouette values were approximately:

```text
Cluster 0 : 0.622
Cluster 1 : 0.588
```

These values describe the separation quality associated with the respective cluster assignments. They should be interpreted together with the overall clustering structure, cluster sizes, and feature profiles.

# 🔬 Methodology

The overall methodology can be summarized as:

```text
1. Understand the raw data
          ↓
2. Analyze distributions and correlations
          ↓
3. Transform skewed features
          ↓
4. Standardize features
          ↓
5. Apply multiple clustering algorithms
          ↓
6. Evaluate clustering quality
          ↓
7. Apply PCA
          ↓
8. Repeat clustering in PCA space
          ↓
9. Compare representations
          ↓
10. Profile clusters in original feature space
```

This structure makes it possible to distinguish between three important sources of variation:

```text
Preprocessing
      │
      ├── Transformation
      └── Scaling

Representation
      │
      ├── Original feature space
      └── PCA space

Clustering Algorithm
      │
      ├── K-Means
      ├── Hierarchical
      ├── DBSCAN / HDBSCAN
      └── GMM
```

# 📏 Evaluation

Because the problem is unsupervised, there is no ground-truth target defining the correct customer segments.

Therefore, several complementary criteria are used.

## Silhouette Score

The Silhouette Score measures how well each observation fits within its assigned cluster compared with the nearest alternative cluster.

The score ranges from approximately:

```text
-1 ───────────── 0 ───────────── +1
```

Higher values generally indicate stronger separation and cohesion.

However, Silhouette Score is not treated as the only criterion.

---

## Elbow Method

For K-Means, inertia is examined across different values of `K`.

The objective is to identify regions where increasing the number of clusters provides diminishing improvements.

---

## Cluster Size

Cluster sizes are examined to detect:

* Extremely small clusters
* Possible over-segmentation
* Dominant clusters
* Potential outlier-driven groups

---

## Cluster Profiling

The final clusters are analyzed in the original feature space.

This is important because PCA coordinates and scaled features are useful for modeling but are not directly meaningful in terms of actual customer spending.

Cluster profiles are therefore examined using statistics such as:

* Mean
* Median
* Minimum
* Maximum
* Standardized feature values

---

# 📈 Results

The experiments demonstrate that clustering quality is strongly affected by **feature representation and preprocessing**, not only by the choice of clustering algorithm.

One of the clearest structures found in the project was obtained using K-Means on the first principal component.

### Selected result

| Representation | Algorithm | Clusters | Silhouette |
| -------------- | --------- | -------: | ---------: |
| PCA — PC0      | K-Means   |        2 | **0.6045** |

The GMM experiments in PCA space produced a broadly similar two-group structure while providing probabilistic membership information.

The project also demonstrates that several clustering algorithms do not necessarily produce equally useful structures on the same representation. In particular, density-based methods can be highly sensitive to the geometry and density of the transformed feature space.

Therefore, the experiments support a broader methodological observation:

> **Choosing an appropriate representation of the data can be as important as choosing the clustering algorithm itself.**

---

# 🧠 Cluster Interpretation

The final clusters are interpreted using the original six spending features:

```text
Fresh
Milk
Grocery
Frozen
Detergents_Paper
Delicassen
```

Standardized cluster profiles are particularly useful for identifying relative spending patterns.

For example:

* Positive standardized values indicate relatively higher spending than the overall dataset average.
* Negative standardized values indicate relatively lower spending.
* Values close to zero indicate behavior closer to the dataset average.

This makes it possible to describe clusters according to their purchasing patterns rather than merely referring to them as `Cluster 0` and `Cluster 1`.

---

# 🔎 Important Finding: PCA Representation

A particularly interesting result is that the strongest observed separation occurred using **PC0 alone**.

The first principal component captures a substantial portion of the overall variance in the six-dimensional spending space.

However, it is important to distinguish:

```text
High explained variance
        ≠
Automatically meaningful clusters
```

PCA maximizes variance, not cluster separation.

The usefulness of PC0 for segmentation therefore comes from the subsequent clustering evaluation rather than from its explained variance alone.

# ⚠️ Limitations

## No Ground Truth

The dataset does not contain predefined customer segment labels.

Consequently, there is no objectively known "correct" clustering against which the models can be directly evaluated.

## Dataset Size

The dataset contains only 440 observations.

Results should therefore be interpreted within the context of this dataset rather than automatically generalized to all wholesale customers.

## Metric Limitations

Silhouette Score provides useful information about geometric separation, but it does not directly measure business usefulness.

## Representation Dependence

Clustering results depend substantially on:

* Transformation
* Scaling
* Outlier treatment
* Feature selection
* Dimensionality reduction

## Business Interpretation

The dataset primarily describes annual spending behavior.

Additional information such as:

* Purchase frequency
* Profitability
* Customer lifetime value
* Customer demographics
* Temporal purchasing patterns

would be required to construct richer business-oriented customer personas.
